# Implementation milestones

## Milestone 1 — Security foundation

Centralized credentials, bcrypt migration, HTTP-only JWT sessions, safe
serialization, authorization, validation, rate limiting, and secure onboarding.

## Milestone 2 — Account and administration workflows

OTP verification, administrator approval, profile ownership, admin reports,
bulk import, notifications, and account-status communication.

## Milestone 3 — Engagement workflows

Mentorship, referral history, event capacity/waitlists/check-in, jobs,
announcements, recognition, community, connections, and contributions.

## Milestone 4 — Explainable recommendations

Mode-specific hybrid ranking, normalized skills, similarity signals,
explanations, feedback, cold-start handling, and offline metrics.

## Milestone 5 — Deployment and engineering quality

Docker Compose, Nginx, Gunicorn, health checks, request tracing, OpenAPI,
automated tests, CI, demo seeding, and final-year documentation.

## Milestone 6 — Frontend resilience and browser quality

Route-level lazy loading, smaller production chunks, global error handling,
SPA-aware proxying, and Playwright coverage for critical journeys.

## Milestone 7 — Real-time communication

JWT-authenticated Socket.IO, stored notifications, direct conversations,
message read state, unread counts, and live frontend delivery.

## Milestone 8 — Adaptive recommendation evaluation

Word/character semantic similarity, bounded feedback adjustments, model
versioning, labelled fixtures, Precision@K, Recall@K, MRR, and NDCG.

## Milestone 9 — Scalability and safety

Paginated reads, recommendation caching and invalidation, background email jobs,
database indexes, and bounded CSV upload validation.

## Milestone 10 — Final project package

Engagement analytics, downloadable CSV reports, seeded demo data, updated API,
architecture and test documentation, plus the demo and viva guide.

## Milestone 11 — Grounded intelligence and graph discovery

Natural-language alumni assistant, confirmed actions, interactive graph,
mutual connections, shortest paths and reproducible model comparison.

## Milestone 12 — Workflow depth

Mentorship goals/milestones/progress and referral application pipeline with
timestamped history.

## Milestone 13 — Analytics, privacy and notifications

MongoDB-backed engagement metrics, privacy/contact controls, blocking, personal
data export, notification preferences and idempotent reminders.

## Milestone 14 — PWA and presentation quality

Installable production PWA, offline shell, accessibility improvements,
reduced-motion support and guided `/demo` presentation mode.

## Milestone 15 — Secure account management

Strong-password change/reset, privacy-safe recovery, hashed expiring reset
tokens, revocable device sessions, login history and logout-all.

## Milestone 16 — Final documentation release

Master report, SRS, database design, use cases/DFDs, API guide, security analysis,
ML evaluation, verified test report, setup/deployment guide and user manual.
